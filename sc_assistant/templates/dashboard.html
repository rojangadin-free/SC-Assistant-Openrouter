Data Conflicts

These are facts your documents state two different ways (for example, two different people listed as dean of the same college). When this happens the assistant has no way to know which one is current, so its answer can change from one question to the next. Pick the correct value once here and the assistant will always use it — the wrong value will be ignored even if it is still written in the PDF.

Announcements

Anything posted here does two things at once: it is pinned at the top of the chat for every student who opens it, and it is given to the assistant as higher authority than the documents. So "classes are suspended tomorrow" both shows up unprompted and changes the answer to "may klase ba bukas?" — which the handbook would otherwise answer with the regular schedule, confidently and wrongly.
